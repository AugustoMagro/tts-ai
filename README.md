# Text To Speach (TTS)

### About

This is a project to transform Text to Speach with AI, i´m using Kokoro as the model.

### How to use

1. Clone the repo and sync the project with UV.
   `git clone https://github.com/AugustoMagro/tts-ai`
   `uv sync`

2. Run the project with FastAPI, it will server at "127.0.0.1:8000"
   `.venv\Script\activate`
   `fastapi run main.py`
