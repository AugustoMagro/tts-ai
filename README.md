# Text To Speech (TTS)

### About

This is a project to transform Text to Speech with AI for you to run localy, i´m using Kokoro as the ai model.

### How to use

1. Clone the repo and sync the project with UV.
   ```
   git clone https://github.com/AugustoMagro/tts-ai
   uv sync
   ```
3. Run the project with FastAPI, it will server at "http/127.0.0.1:8000/".
   ```
   .venv\Script\activate
   fastapi run main.py
   ```
